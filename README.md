# IncomeIQ 💰
### Smart Income Prediction Using Machine Learning

IncomeIQ is a machine learning project that predicts whether an individual's annual income is above or below $50,000 using the Random Forest Classification algorithm.

## Project Overview
- **Project Name:** IncomeIQ
- **Algorithm:** Random Forest Classifier
- **Dataset:** Adult Census Income
- **Dataset Size:** 32,537 records
- **Problem Type:** Binary Classification

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- Joblib

## Model Performance

| Metric | Score |
|---|---:|
| Accuracy | 84.96% |
| Precision | 72.36% |
| Recall | 60.78% |
| F1-Score | 66.07% |

## Features
- Income prediction
- Data visualization
- Machine learning insights
- Feature importance analysis
- Interactive Streamlit dashboard
